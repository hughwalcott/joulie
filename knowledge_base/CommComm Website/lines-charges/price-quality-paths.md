# Electricity lines price-quality paths (default and customised)

A **price-quality path** is the main tool the Commerce Commission uses to regulate lines monopolies. It **limits what a business can recover from consumers** (either the maximum average prices it can charge, or its total allowable revenue) and **sets minimum quality-of-service standards** — so a business can't cut service quality to maximise profit under the cap.

## The two types

- **Default price-quality path (DPP)** — applies to most price-quality-regulated distributors. The Commission uses relatively low-cost methods to set these paths for the **16** non-consumer-owned distributors subject to price-quality regulation (and a separate individual path applies to Transpower).
- **Customised price-quality path (CPP)** — if a default path doesn't suit a particular business's circumstances, it can apply for and propose its own customised path using more detailed, business-specific information (assessed with independent expert input). For example, **Aurora Energy** has been on a customised path and transitions back to the default path in 2026.

A **reopener** lets a distributor request a change to its path mid-period in defined circumstances.

## The main components of a DPP

- **Starting prices** — the maximum prices/revenues allowed at the start of the regulatory period.
- **Rate of change ("CPI-X")** — how fast maximum allowed prices can rise each year, expressed as inflation (CPI) **minus an "X-factor"** (a set number of percentage points), so real prices are constrained.
- **Minimum quality standards** — the service-quality levels the business must meet.

A DPP normally runs for about **five years** before being **reset** for the next period, which is an opportunity to set appropriate price and quality controls that promote the long-term benefit of consumers under Part 4 of the Commerce Act.

## The key limit to remember

The Commission regulates the **average prices / total revenue** a distributor can charge — it does **not** set the price for any individual consumer. Distributors can structure prices across customers in various ways to meet the regulated average, and they set actual charges consistent with the Commission's limits and the **Electricity Authority's pricing methods and principles**.
