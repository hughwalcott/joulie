# Joulie policy/authority training corpus

Training data covering the official-source areas the Joulie test suite draws on but Joulie lacked.
Save this tree into your Joulie data area (e.g. C:\Joulie-policy-data).

Conventions match the other Joulie corpora: YAML front matter with source_url, source_type,
publisher/authority, source_date, source_date_basis, retrieved, document_id. Faithful restructured
content; every time-sensitive figure carries a ⚠ currency note (the test suite explicitly rewards
appropriate hedging on unsettled/fast-changing items).
